# Arena Brasil

A fully offline, native English-language football companion for iPhone and iPad. Open `ArenaBrasil.xcodeproj` and run the `ArenaBrasil` scheme. Minimum iOS 17, Swift 6.

## Included

- Home with featured match, search, competition filters and personalised ordering.
- Calendar with all, in-progress sample and favourite filters.
- Match centre with events, line-ups, statistics, previous meetings and team comparison.
- Team profiles with form, fixtures, squads and league position.
- Competitions with computed standings, rounds and scorers.
- Persisted favourite clubs/competitions, saved matches and local reminders.

All content ships inside the app. There is no server, API, network adapter, connection monitor, online mode, refresh request, login or API key. The catalogue is available immediately on first launch and after restarting. Removing the former optional offline preference preserves existing favourites and saved matches.

The football season is explicitly illustrative, not current real-world coverage. It is the built-in content of this standalone app, not a placeholder for an external integration. Notification permission is requested only when scheduling a local reminder. No purchases, advertising or tracking.
